# PFOA docking ligand

`pfoa_ligand.pdbqt` is the deposited PFOA input used by the Vina-GPU docking
stage. The file contains 26 atoms with AutoDock atom types and partial charges,
a complete ROOT/BRANCH torsion tree, and eight active torsions (`TORSDOF 8`).

The configured path is `paths.pfoa_ligand_pdbqt` in `config/default.yaml`.
The SHA-256 digest is recorded in `SHA256SUMS.txt` for integrity checking.
