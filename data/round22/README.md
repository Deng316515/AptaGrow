# Round-22 candidate and clustering data

This directory provides the complete 27-member, 23-nt candidate pool selected
for the final AptaGrow analysis.

## Files

- `round22_all_sequences_clustered_apt.csv` contains sequence, cluster label,
  binding energy (BE), folding free energy (FE), and dot-bracket secondary
  structure for all 27 candidates.
- `selected_candidates.jsonl` is the machine-readable input for
  `aptagrow prepare-structures` and the subsequent multimodal workflow.
- `representative_aptamers.csv` lists Apt1-Apt6. Each entry is the lowest-BE
  member of its cluster, with clusters ordered from 0 through 5.

BE and FE values are expressed in kcal/mol. Cluster labels are categorical
identifiers; their numeric values do not indicate a ranking of cluster quality.

## Structure preparation

The PDBQT files required for six-view rendering and spatial-graph construction
are generated by the public AptaGrow structure-preparation command:

```bash
aptagrow --config config/default.yaml prepare-structures \
  --input data/round22/selected_candidates.jsonl
```

The command uses the deposited A/C/G/U nucleotide templates, SimRNA 3.20,
PyMOL 2.5.4, and MGLTools 1.5.7. It writes the generated structures and an
updated JSONL manifest to `results/03_evolution/round_22/`.
